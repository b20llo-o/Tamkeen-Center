# منظومة مركز تمكين

نموذج تفاعلي لمنظومة تعليمية ثنائية اللغة (عربي/إنجليزي): واجهة عامة للزوار + لوحات تحكم للطلاب والمعلمين والإدارة.

## التشغيل محلياً

هذا المشروع **HTML + React** يعمل في المتصفح مباشرةً (دون خطوة بناء). يحتاج فقط خادم ملفات ثابت لأنه يستخدم صوراً وفيديو.

### الطريقة الأولى — عبر npm

```bash
npm install      # يثبّت خادم serve مرة واحدة
npm run dev      # يشغّل الموقع على http://localhost:8000
```

ثم افتح في المتصفح العنوان الجذر مباشرةً (سيُحوّلك `index.html` تلقائياً إلى المنظومة):

```
http://localhost:8000
```

### الطريقة الثانية — بدون npm

إن كان لديك Python:

```bash
python3 -m http.server 8000
```

أو استخدم إضافة **Live Server** في محرّر VS Code (زر "Go Live").

## بنية الملفات

```
منظومة تمكين.html      ← الصفحة الرئيسية (نقطة الدخول)
src/                    ← مكوّنات React (JSX)
  core.jsx              ← الألوان، النصوص ثنائية اللغة، البيانات، الأيقونات
  ui.jsx                ← عناصر واجهة مشتركة
  public.jsx            ← الموقع العام (الواجهة، الدبلومات، عن المركز…)
  auth.jsx              ← التسجيل وتسجيل الدخول
  dash-common.jsx       ← هيكل اللوحات + الوارد + الإعلانات + الآلة الحاسبة
  student.jsx           ← لوحة الطالب
  teacher.jsx           ← لوحة المعلم
  mgmt-tools.jsx        ← أدوات الإدارة (الجداول، الإعلانات، السحابة، الدرجات)
  management.jsx        ← لوحة الإدارة/المدير
  app.jsx              ← التوجيه، الجلسة، الحفظ، العمليات
assets/                 ← الشعار، الصور، الفيديو
```

## ⚠️ ملاحظة عن البيانات

حالياً تُحفظ كل البيانات في **localStorage داخل متصفح كل مستخدم** — أي أنها لا تتزامن بين الأجهزة. لتحويله إلى نظام حقيقي متعدد المستخدمين يلزم ربطه بقاعدة بيانات سحابية (مثل Supabase).
